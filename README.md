# Hash Set
This file is a very simple implementation in C/C++ of a basic hash set that uses Extendible hashing.

For this implementation **no containers** (built in C/C++ or otherwise) were used, but rather **only arrays**.

The specifications and features od this Set adheres to these mentioned in the requirements document o the project defined in 051024 Algorithmen und Datenstrukturen 1 class of thee University Of Vienna, thus not meant to replace or have the full functionality of a modern C++ Set.
